# Gym Registration Form

## 🌐 Live Demo  
[View Live](https://abdulkarimmziya.github.io/form_validation/)  

## 🚀 Features  
- Responsive two-column layout with a blurred background image  
- Dynamic form validation (email, password strength, and confirmation)  
- Friendly error messaging  
- Social media registration buttons  
- Clean, modern design with gradient overlays

## 🛠️ Technologies Used  
- HTML5  
- CSS3 (Grid, Flexbox, Custom Styling)  
- JavaScript (Form validation, DOM manipulation)

## 🧠 Concepts Demonstrated  
- Responsive design using CSS Grid & Flexbox  
- Custom background overlays with `linear-gradient` and `blur()`  
- Real-time client-side form validation using JS  
- Semantic HTML and accessibility practices  
- Separation of concerns: HTML structure, CSS styling, JS logic
